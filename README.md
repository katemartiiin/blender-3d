# blender-3d

A personal playground for practicing my [Blender](https://www.blender.org/) skills. Nothing serious here — just a fun creative project where I model, texture, and render 3D scenes while learning the ropes.

## About

This repo is where I keep the `.blend` files and renders from my Blender experiments. I'm using it to build up my confidence with modeling, materials, lighting, and rendering one project at a time.

## Projects

- **Donut** — my take on the classic Blender starter tutorial.
- **Dubu** — a character model inspired by Dahyun of TWICE.

## How to open

1. Install [Blender](https://www.blender.org/download/) (free & open source).
2. Clone this repo.
3. Open any `.blend` file in Blender and start exploring!

> ℹ️ The `.blend1` files are Blender's automatic backups of the previous save — safe to ignore.
